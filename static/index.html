Architecture & Security Philosophy

"Never Trust the LLM"

1. The Core Philosophy: Deterministic Code Over Probabilistic LLM

A central design decision in this system is: The LLM provides conversational guidance, but deterministic Python code strictly enforces all business rules, authorization, and data safety.

Why AI Security is Harder than Traditional Software: In standard APIs, fixed server-side if/else statements cannot be rewritten by customer input. With LLMs, probabilistic models can be socially engineered or injected via natural language speech. If given unconstrained tool authority, a manipulated LLM could issue unauthorized cancellations or leak competitor/customer records. Therefore, risk multiplies with tool permissions, and the LLM must never be trusted with business logic.

2. The 4-Layer Guardrail Defense Implemented in Aria

Layer 1

Input Guardrails

• Client RMS VAD: Filters ambient noise & room echo before streaming to server.
• ASR Hallucination Filter: Discards Whisper noise tokens ("the", "you") & low-confidence audio.
• Untrusted Delimiters: Customer input is enclosed in <customer_utterance> tags.

Layer 2

System & Persona Guardrails

• Aria Persona: Friendly, concise Indian English customer specialist.
• Injection Immunity: Hard instructions to ignore prompt override commands or administrative claims.
• Out-of-Scope Deflection: Non-brand requests (flights, coding) are politely rejected without invoking backend tools.

Layer 3

Tool & Deterministic Guardrails

• IDOR Caller Verification: Verifies order ownership (Priya cannot access Rahul's ORD-102).
• 2-Step Cancellation Verification: Requires explicit double-confirmation before database commit.
• Code-Computed Policies: Python strictly calculates 7-day returns, ₹499 shipping, and ₹2,500 COD.

Layer 4

Output Guardrails

• Audio Speech Filter: Strips markdown symbols, asterisks, and currency signs (₹) for natural speech.
• Pydantic Schema Validation: Post-call summaries are strictly validated into typed JSON (CallSummary).
• Zero Data Leakage: Prevents disclosure of other customer addresses or courier API secrets.
